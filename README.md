Quiz Game

A simple Python-based Quiz Game that asks multiple-choice questions and calculates the final score and percentage.

Features

- Multiple-choice questions
- Correct and wrong answer checking
- Automatic score calculation
- Percentage calculation
- Performance message
- Play Again option
- Beginner-friendly Python project

Technologies Used

- Python

How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the "quiz.py" file.
4. Run the program.
5. Enter your answer as A, B, C, or D.
6. View your final score and percentage.
